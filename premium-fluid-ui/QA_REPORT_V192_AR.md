# تقرير فحص الإصدار v1.9.2 — Premium Fluid UI

## حالة الإصدار

**ملف الـSkill قابل للتثبيت** في Codex وAntigravity وبيئات Agent Skills التي تقرأ `SKILL.md`.

تم تحديث قاعدة الإصلاح: جميع الانحرافات **المثبتة** في أحجام الخطوط وأوزانها والهوامش والمسافات وأعمدة الديسكتوب وتناسق الموبايل **إلزامية التصحيح** أياً كانت الأولوية P0/P1/P2. الحفاظ على هوية الموقع الأصلية إلزامي أيضاً. نتائج الـStatic Scan مرشحات لا يحق اعتبارها عيوباً مؤكدة بدون فحص.

## حدود الفحص

- نجاح الاختبارات يعني أن **الأدوات والأمثلة المرجعية تعمل**، وليس أن جميع مواقع المستخدم أصبحت مطابقة بالفعل. تطبيق قواعد الإصلاح على أي موقع يتطلب فحص صفحاته وبياناته وتفاعلاته وصور Before/After.
- مدخل `--real-zoom` يختبر CSS zoom وتغيير حجم خط الجذر داخل Chromium؛ لا يُعد اختباراً كاملاً لقائمة Zoom الأصلية في المتصفح أو تكبير نص نظام التشغيل أو جهاز موبايل فعلي.
- لم تُعدّل الحزمة أي Repository، ولم تشغّل Server للمستخدم، ولم تقم بـ Deployment.
- يمكن أن تكون بعض النتائج Heuristic أو Intentional Design. كل نتيجة تُصنّف، وتُصلح إن ثبتت مخالفة، أو تُوثّق كاستثناء محسوب.

## الاستخدام

1. فك `premium-fluid-ui-v1.9.2.zip` مع الاحتفاظ بمجلد `premium-fluid-ui` كاملاً.
2. انسخ المجلد إلى `<project>/.agents/skills/premium-fluid-ui/` أو مسار الـSkills العام.
3. داخل المشروع شغّل فحوص الـSkill على بيئة Preview/Dev قائمة ومصرح بها، ثم طبّق الإصلاحات وفق سجل المخالفات في `references/mandatory-conformance.md`.
4. لا تطبّق `fluid_codemod.py --apply` بدون معاينة Diff ونطاق معتمد و`--reviewed`، ولا تعمم تحويل الأوزان أو الأعمدة بدون تحديد سبب مثبت.
